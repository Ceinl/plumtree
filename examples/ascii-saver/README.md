# ASCII saver

A zero-setup animated screensaver for an SSH endpoint. It demonstrates SDK
timers, resize events, styles, and a custom component that still renders only
through Plumtree's safe cell grid.

```bash
pt dev --ssh
# or, after deployment
ssh <owner>/ascii-saver@plumtree.app
```

Press `q`, `Esc`, or `Ctrl-C` to disconnect.
